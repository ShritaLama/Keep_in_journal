# keepinjournal

A new Flutter project. KeepInJournal is a simple productivity and journaling application built using Flutter and Dart. The app helps users organize daily tasks, keep notes, and manage activities efficiently through a clean and user-friendly interface.

## Features

- Add and manage daily tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean UI
- Responsive mobile interface
- Lightweight and easy to use

## Technologies Used

- Flutter
- Dart
